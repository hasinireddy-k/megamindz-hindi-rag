Technical Decisions
Why Multilingual Embeddings?
Enables true cross-lingual semantic matching (English queries matching Hindi passages) without brittle machine translation layers.
Why ChromaDB?
Lightweight, fully local persistent vector store that eliminates external cloud dependencies and allows complete repository regeneration via ingest.py.
Why Section-Aware Chunks?
Preserves semantic cohesion across Devanagari sentence delimiters (Purna Viram '।') without dissecting compound conjunct characters midway.
Why Metadata Attribution?
Provides absolute traceability for AI/ML audits, verifying exact document page numbers, section headers, and cosine similarity scores.
